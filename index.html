Salud Digital Colombia S.A.S.

Proyecto Integrador de Cloud Computing basado en una arquitectura Cloud Native sobre AWS.

¿Quiénes Somos?

Salud Digital Colombia S.A.S. es una empresa ficticia creada para el proyecto académico. La propuesta consiste en migrar una plataforma del sector salud hacia una arquitectura Cloud Native utilizando los servicios de Amazon Web Services (AWS).

Arquitectura AWS

🌐

Amazon VPC

Red privada segura para todos los recursos de la aplicación.

🐳

EC2 + Docker

Ejecución de microservicios de manera flexible y escalable.

🗄️

Amazon RDS

Base de datos administrada con alta disponibilidad Multi-AZ.

☁️

Amazon S3

Almacenamiento seguro para archivos clínicos y documentos.

🔐

AWS IAM

Administración segura de usuarios, permisos y roles.

📈

CloudWatch

Monitoreo del rendimiento y generación de alertas.

🛡️

AWS WAF

Protección perimetral frente a amenazas web.

💾

AWS Backup

Copias de seguridad automáticas y recuperación de información.
